# Menu image naming

Store each menu item image at `/images/menu/<slug>.jpg`, where `<slug>` is
the lowercase item name with non-alphanumeric runs replaced by hyphens.
For example, `Masala Dosa` uses `masala-dosa.jpg`.

Use a photo that depicts the actual dish. The catalogue seed does not download
or generate images; its image report lists menu slugs that still need an image.
